С учетом 350+ ВМ мы заложим **высокую параллельность (Goroutines + Worker Pool)**, чтобы проверки не затягивались на долгие минуты, а также эффективное хранение истории в памяти с возможностью очистки.

## 🏗 Архитектурный план проекта (Roadmap)

### Этап 1: Структура и Конфигурация

1. **`config.go`**: Описание структуры YAML (ВМ, сервисы, контейнеры, расписание крона, параметры бота) + функции чтения и перезаписи YAML-файла «на лету» (с соблюдением thread-safety через mutex).
2. **`config.yaml`**: Эталонный файл конфигурации.

### Этап 2: SSH & Engine проверок

3. **`ssh.go`**: Модуль подключения по SSH-ключам (с таймаутами) и выполнение команд (`systemctl`, `docker inspect`).
4. **`checker.go`**: Движок проверок. Worker Pool для параллельного опроса 350+ ВМ, агрегация результатов и генерация JSON-отчета.

### Этап 3: Хранение и Уведомления

5. **`storage.go`**: Хранение истории проверок в памяти (In-Memory) с методами получения, добавления и **полной очистки**.
6. **`notifier.go`**: Клиент для отправки готового JSON-отчета в твой мессенджер BotX (`https://bot01.clouds.org.ru/...`).
7. **`scheduler.go`**: Крон-планировщик (проверка в 00:00, отсылка отчета в 08:00).

### Этап 4: Web UI, API & Healthcheck

8. **`health.go`**: Энпоинт `/healthcheck` (отдает `ItsOk` для Прометеуса).
9. **`handlers.go`**: REST API ендпоинты (ручной запуск проверок, получение статусов, очистка истории, сохранение конфига).
10. **`index.html`**: Лаконичный и удобный UI в стиле *VictoriaLogs* (темная тема, поиск/фильтрация, быстрые статусы, кнопка «Запустить проверку»).
11. **`main.go`**: Сборка и запуск всего приложения.

# Подключение зависимости
> Для работы планировщика необходимо добавить библиотеку cron:

```Bash
go mod init ssh-checker
go get github.com/robfig/cron/v3
```
🛠 Как запустить и протестировать сервис
### 1. Подготовка зависимостей
Убедись, что выкачаны все необходимые модули:

```Bash
go get gopkg.in/yaml.v3
go get golang.org/x/crypto/ssh
go get github.com/robfig/cron/v3
go mod tidy
```
### 2. Запуск приложения
```Bash
go run cmd/main.go
```
### 3. Проверка работы
Web UI: Перейди в браузере по адресу http://localhost:8080.

Healthcheck: Выполни curl http://localhost:8080/healthcheck (вернет ItsOk).

Ручной запуск: Нажми кнопку «Run Check Now» в интерфейсе или вызови:

```Bash
curl -X POST http://localhost:8080/api/check
```
